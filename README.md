# Finportal for Mac and Windows

The Finportal desktop app: Finportal in a window of its own, with incoming
calls shown as a popup on your computer.

Download the latest version from
[Releases](https://github.com/Finportal-GmbH/finportal-desktop/releases/latest).
Once installed, the app keeps itself up to date.

- **Mac (Apple silicon):** the `.dmg` file.
- **Windows:** not released yet.

You need a Finportal account to use it: <https://app.finportal.ch>.

This repository holds only the built app. It has no source code and takes no
issues or pull requests.
